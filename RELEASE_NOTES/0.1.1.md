# MenuBarUSB-TB 0.1.1

This release improves installation without changing the app's device
discovery or privacy behavior.

## Installation

- New compact installer DMG with a clear drag-and-drop path from
  `MenuBarUSB-TB.app` to **Programme** (`/Applications`)
- Deliberately arranged Finder window, instruction and background instead of
  an unarranged folder

## Compatibility

**This release supports Apple Silicon Macs (`arm64`) running macOS 13 or newer.
Intel Macs are not supported.**
