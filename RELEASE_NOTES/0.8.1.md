# MenuBarIO 0.8.1

This patch release switches the local Developer ID signing default to the G2 certificate. The release script selects the unambiguous SHA-1 fingerprint `D548540E7FE1BD9B3C4518CC02D8786E1BFEB885` and checks that the selected identity is valid before creating an artifact. `MENUBARIO_SIGNING_IDENTITY` remains available as an override.

The source handoff also records the earlier archival and removal of legacy MenuBarUSB-TB and PortGlance GitHub releases. Their verified local archive is excluded from Git. This does not change the app's behavior.

Version 0.8.1, build 15. Apple Silicon (`arm64`), macOS 15+.
GPL-3.0-or-later; `LICENSE.upstream` preserves the original MIT notice.

([source archive](https://github.com/r3d42-git/MenuBarIO/archive/refs/tags/v0.8.1.tar.gz)).
