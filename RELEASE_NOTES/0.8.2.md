# MenuBarIO 0.8.2

USB devices connected directly to newer Macs now occupy their physical USB-C
host port when macOS provides an explicit `UsbIOPort` reference. This prevents
an occupied port from appearing free while its device remains in Other USB Devices.

Thunderbolt/USB4 docks now report active DisplayPort outputs. If macOS does not
identify the physical display connector, otherwise unassigned dock ports show
**Occupancy unknown** instead of **Free**. Details and diagnostic exports explain
the limitation; existing USB and Thunderbolt assignments remain intact.
Display configuration changes trigger a delayed topology refresh.

Version 0.8.2, build 16. Apple Silicon (`arm64`), macOS 15+.
GPL-3.0-or-later; the preserved MIT notice remains in LICENSE.upstream.
[Corresponding source](https://github.com/r3d42-git/MenuBarIO/tree/v0.8.2)
([source archive](https://github.com/r3d42-git/MenuBarIO/archive/refs/tags/v0.8.2.tar.gz)).

Validation: 110 local tests, static analysis and the Apple Silicon archive passed.
Live Mac Studio checks covered direct USB assignment, dock replugging and active
DisplayPort detection. Automated visual acceptance, a clean-Mac installation,
and a fresh macOS 15 hardware check remain unverified.

# MenuBarIO 0.8.2 — Deutsch

Direkt an neueren Macs angeschlossene USB-Geräte belegen jetzt ihren physischen
USB-C-Hostport, wenn macOS einen expliziten `UsbIOPort`-Verweis liefert.
Dadurch erscheint ein belegter Anschluss nicht mehr als frei, während sein
Gerät unter Weitere USB-Geräte steht.

Thunderbolt-/USB4-Docks zeigen jetzt aktive DisplayPort-Ausgänge an. Liefert
macOS keine eindeutige Zuordnung zur Bildschirmbuchse, steht an sonst nicht
zugeordneten Dock-Ports **Belegung unbekannt** statt **Frei**. Details und
Diagnoseexport erläutern diese Grenze; bestehende USB- und Thunderbolt-Zuordnungen
bleiben erhalten. Änderungen der Bildschirmkonfiguration lösen eine verzögerte
Aktualisierung der Topologie aus.

Version 0.8.2, Build 16. Apple Silicon (`arm64`), macOS 15+.
GPL-3.0-or-later; der erhaltene MIT-Hinweis steht in LICENSE.upstream.
[Zugehöriger Quellcode](https://github.com/r3d42-git/MenuBarIO/tree/v0.8.2)
([Quellcodearchiv](https://github.com/r3d42-git/MenuBarIO/archive/refs/tags/v0.8.2.tar.gz)).

Prüfung: 110 lokale Tests, statische Analyse und Apple-Silicon-Archiv erfolgreich.
Live-Prüfungen am Mac Studio umfassten direkte USB-Zuordnung, Umstecken am Dock
und aktive DisplayPort-Erkennung. Automatische Sichtprüfung, Neuinstallation
auf einem frischen Mac und erneute Prüfung auf macOS-15-Hardware bleiben offen.
