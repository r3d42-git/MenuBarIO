# MenuBarUSB-TB 0.1.0

MenuBarUSB-TB is a native menu-bar utility for connected USB, Thunderbolt and
USB4 hardware. It is an independent MIT-licensed fork of MenuBarUSB with
improved Thunderbolt/USB4 discovery and a device-first list.

## Compatibility

**This release supports Apple Silicon Macs (`arm64`) running macOS 13 or newer.
Intel Macs are not supported.**

## Highlights

- USB devices and USB hubs in separately collapsible groups
- Thunderbolt and USB4 devices with negotiated link speed and protocol
- Prevention of duplicate Thunderbolt dock entries caused by USB-C Billboard
  companion interfaces
- Optional local Ethernet-link indicator without traffic monitoring
- No bundled audio, donation functionality, telemetry, analytics, crash
  reporting or automatic update checks

# MenuBarUSB-TB 0.1.0 – Deutsch

MenuBarUSB-TB ist ein natives Menüleistenprogramm für angeschlossene USB-,
Thunderbolt- und USB4-Hardware. Es ist ein unabhängiger Fork von MenuBarUSB
unter MIT-Lizenz mit verbesserter Thunderbolt-/USB4-Erkennung und einer
geräteorientierten Liste.

## Kompatibilität

**Diese Version unterstützt Apple-Silicon-Macs (`arm64`) mit macOS 13 oder
neuer. Intel-Macs werden nicht unterstützt.**

## Wichtige Funktionen

- USB-Geräte und USB-Hubs in getrennt einklappbaren Gruppen
- Thunderbolt- und USB4-Geräte mit ausgehandelter Link-Geschwindigkeit und
  Protokoll
- Verhinderung doppelter Thunderbolt-Dock-Einträge durch USB-C-Billboard-
  Begleitschnittstellen
- Optionale lokale Ethernet-Link-Anzeige ohne Verkehrsüberwachung
- Keine eingebundenen Audiodateien, Spendenfunktionen, Telemetrie, Analyse,
  Crash-Berichte oder automatischen Update-Prüfungen
