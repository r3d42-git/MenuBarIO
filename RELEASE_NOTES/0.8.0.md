# MenuBarIO 0.8.0

- Requires an Apple-Silicon Mac and macOS 15 or newer.
- Removes the separate macOS 13/14 settings window and legacy menu-bar path.
- Keeps settings integrated into the device menu on all supported systems.

Intel and macOS 13/14 users can continue using the unchanged
[MenuBarIO 0.7.2](https://github.com/r3d42-git/MenuBarIO/releases/tag/v0.7.2).
Critical fixes for that version may be considered individually; regular Intel
feature updates are no longer planned.

Version 0.8.0, build 14. Apple Silicon (`arm64`), macOS 15+.
GPL-3.0-or-later; LICENSE.upstream preserves the original MIT notice.
[Corresponding source](https://github.com/r3d42-git/MenuBarIO/tree/v0.8.0)
([source archive](https://github.com/r3d42-git/MenuBarIO/archive/refs/tags/v0.8.0.tar.gz)).

Validation: 106 tests, static analysis, architecture/minimum-OS checks and Debug
launch passed with Xcode 27 on macOS 27. The platform guard rejects Universal
binaries and incorrect minimum versions. The maintainer requested publication
with the macOS 15 physical runtime and new UI acceptance still pending;
automated UI inspection timed out. A fresh clean-Mac installation was not tested.

# MenuBarIO 0.8.0 — Deutsch

- Benötigt einen Mac mit Apple Silicon und macOS 15 oder neuer.
- Entfernt das separate Einstellungsfenster für macOS 13/14 und den alten
  Menüleistenpfad.
- Die Einstellungen sind auf allen unterstützten Systemen im Gerätemenü integriert.

Für Intel und macOS 13/14 bleibt
[MenuBarIO 0.7.2](https://github.com/r3d42-git/MenuBarIO/releases/tag/v0.7.2)
unverändert verfügbar. Kritische Korrekturen können im Einzelfall geprüft werden;
regelmäßige Intel-Funktionsupdates sind nicht mehr geplant.

Version 0.8.0, Build 14. Apple Silicon (`arm64`), macOS 15+.
GPL-3.0-or-later; LICENSE.upstream erhält den ursprünglichen MIT-Hinweis.
[Zugehöriger Quellcode](https://github.com/r3d42-git/MenuBarIO/tree/v0.8.0)
([Quellcodearchiv](https://github.com/r3d42-git/MenuBarIO/archive/refs/tags/v0.8.0.tar.gz)).

Prüfung: 106 Tests, statische Analyse, Architektur-/Mindestversionsprüfung und
Debug-Start mit Xcode 27 unter macOS 27 erfolgreich. Die Plattformprüfung weist
Universal-Binaries und falsche Mindestversionen zurück. Der Maintainer hat die
Veröffentlichung bei noch ausstehendem physischen macOS-15-Laufzeittest und neuer
UI-Abnahme angefordert; die automatisierte Sichtprüfung endete im Timeout.
Eine Installation auf einem frischen Mac wurde nicht getestet.
