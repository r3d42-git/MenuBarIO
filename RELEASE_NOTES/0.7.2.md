# MenuBarIO 0.7.2

Maintenance update for macOS 27 and Xcode 27.

- Fixes compilation with the macOS 27 SDK: the deprecated USB socket macro
  no longer imports into Swift, so the app reads its identical registry key.
- Preserves explicit USB socket assignment and the existing fallback when
  macOS provides no socket information. No guessed port mappings are added.

Universal (`arm64`, `x86_64`), macOS 13+. Version 0.7.2, build 13.
GPL-3.0-or-later; LICENSE.upstream preserves the original MIT notice.
App and DMG contain LICENSE, LICENSE.upstream, NOTICE and SOURCE.md.
[Corresponding source: v0.7.2](https://github.com/r3d42-git/MenuBarIO/tree/v0.7.2)
([source archive](https://github.com/r3d42-git/MenuBarIO/archive/refs/tags/v0.7.2.tar.gz)).

Validation: 106 tests, static analysis and Universal archive passed with
Xcode 27 on macOS 27. The new Debug build launched and the maintainer confirmed
its appearance. Physical direct-USB replug, Intel/MacBook and clean-Mac tests
were not newly performed for this SDK compatibility correction.

# MenuBarIO 0.7.2 — Deutsch

Wartungsupdate für macOS 27 und Xcode 27.

- Behebt den Build mit dem macOS-27-SDK: Das veraltete USB-Port-Makro lässt
