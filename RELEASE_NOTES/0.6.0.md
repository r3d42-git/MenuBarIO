# MenuBarIO 0.6.0

This release makes hardware refreshes more resilient and adds a privacy-aware
Markdown export for sharing a readable snapshot of the visible hardware
topology.

**USB, Thunderbolt, USB4 & Bluetooth Inspector for macOS**

## Changes

- Coordinates USB/Thunderbolt, Bluetooth, power and Ethernet refreshes through
  one lifecycle-aware path used by the footer, wake and session activation
- Coalesces adjacent refresh requests and shows a compact activity state while
  preventing overlapping discovery runs
- Distinguishes ready, refreshing, stale and unavailable source states; a
  failed refresh keeps the last valid device snapshot visible
- Reports a powered-off Bluetooth controller explicitly while preserving a
  legitimate empty scan as zero devices
- Exports a structured `.md` hardware report through the native macOS save
  panel, following the same group and topology order as the app
- Labels names, vendors, protocols, negotiated speeds, port maxima and unknown
  hub assignments without exporting serial numbers, Bluetooth addresses,
  location IDs, stable internal IDs, usernames or paths
- Adds explicit context-menu copies for Bluetooth devices and Thunderbolt ports
  while retaining the existing detailed USB-device copy
- Unifies the project, app and test deployment target at macOS 13.0 and keeps
  the Ventura/Sonoma compatibility implementation active

## Compatibility and privacy

- Universal app for Apple Silicon (`arm64`) and Intel (`x86_64`) Macs running
  macOS 13 or newer
- The Markdown exporter receives access only to the file selected in the native
  save panel; access is not retained
- Device and power information remains local; the app contains no telemetry,
  analytics, update checks or network client code

## Validation note

The complete local gate passed with 76 automated tests, static analysis,
privacy and localization audits, the macOS 13 deployment-target audit and the
Universal build. The integrated settings view and native Markdown save panel
were checked on macOS 26.

Approved release exception: the macOS 13/14 legacy-settings smoke test and the
new physical coordinated-refresh, sleep/wake and failure-state cases on Apple
Silicon and the supported Intel/T2 Mac were not repeated for this release.
Automated Intel CI and the `x86_64` slice do not constitute those physical
checks.

# MenuBarIO 0.6.0 – Deutsch

Dieses Release macht Hardware-Aktualisierungen robuster und ergänzt einen
datenschutzgerechten Markdown-Export für eine gut lesbare Momentaufnahme der
sichtbaren Hardwaretopologie.

**USB-, Thunderbolt-, USB4- & Bluetooth-Inspektor für macOS**

## Änderungen

- Koordiniert die Aktualisierung von USB/Thunderbolt, Bluetooth,
  Stromversorgung und Ethernet über einen gemeinsamen Lebenszykluspfad für
  Fußzeile, Aufwachen und Sitzungsaktivierung
- Führt unmittelbar aufeinanderfolgende Anforderungen zusammen, zeigt einen
  kompakten Aktivitätszustand und verhindert überlappende Erkennungsläufe
- Unterscheidet bereite, laufende, möglicherweise veraltete und nicht
  verfügbare Quellen; bei einem Fehler bleibt der letzte gültige Gerätestand
  sichtbar
- Benennt einen ausgeschalteten Bluetooth-Controller ausdrücklich und erhält
  einen gültigen leeren Scan weiterhin als null Geräte
- Exportiert über den nativen macOS-Speicherdialog einen strukturierten
  `.md`-Hardwarebericht in derselben Gruppen- und Topologiereihenfolge wie die
  App
- Beschriftet Namen, Anbieter, Protokolle, ausgehandelte Geschwindigkeiten,
  Port-Maxima und unbekannte Hub-Zuordnungen, ohne Seriennummern,
  Bluetooth-Adressen, Location-IDs, stabile interne IDs, Benutzernamen oder
  Pfade auszugeben
- Ergänzt ausdrückliche Kontextmenü-Kopien für Bluetooth-Geräte und
  Thunderbolt-Ports und erhält die vorhandene detaillierte USB-Gerätekopie
- Vereinheitlicht das Deployment Target von Projekt, App und Tests auf macOS
  13.0 und erhält die Kompatibilitätsimplementierung für Ventura und Sonoma

## Kompatibilität und Datenschutz

- Universal-App für Apple-Silicon- (`arm64`) und Intel-Macs (`x86_64`) mit
  macOS 13 oder neuer
- Der Markdown-Export erhält nur Zugriff auf die im nativen Speicherdialog
  gewählte Datei; dieser Zugriff wird nicht gespeichert
- Geräte- und Strominformationen bleiben lokal; die App enthält weder
  Telemetrie, Analysen, Update-Abfragen noch Netzwerk-Client-Code

## Validierungshinweis

Die vollständige lokale Prüfkette war mit 76 automatischen Tests, statischer
Analyse, Datenschutz- und Lokalisierungs-Audits, dem Audit des
macOS-13-Deployment-Targets und dem Universal-Build erfolgreich. Die
integrierte Einstellungsansicht und der native Markdown-Speicherdialog wurden
unter macOS 26 geprüft.

Genehmigte Release-Ausnahme: Der Starttest der klassischen Einstellungen unter
macOS 13/14 sowie die neuen physischen Fälle für koordinierte Aktualisierung,
Sleep/Wake und Fehlerzustände auf Apple Silicon und dem unterstützten
Intel-/T2-Mac wurden für diesen Release nicht wiederholt. Automatische
Intel-CI und der `x86_64`-Slice stellen diese physischen Prüfungen nicht dar.
