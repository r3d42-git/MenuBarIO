# MenuBarUSB-TB 0.1.2

This release adds Universal Mac support and hardens the app's local-only
device-monitoring boundary.

## Compatibility

- Universal app for Apple Silicon (`arm64`) and Intel (`x86_64`) Macs running
  macOS 13 or newer
- Version 0.1.1 remains Apple-Silicon-only

## Changes

- More reliable refresh coalescing for USB, Thunderbolt and USB4 device events
- Safer handling of device metadata shown in the menu bar
- Removes unneeded user-file and outbound-network entitlements; the app keeps
  only its sandbox and USB-device permissions
- CI now runs the test suite natively on Apple Silicon and Intel, and the
  release checks both executable slices

## Validation note

The release artifact is built and checked for both executable slices. Dedicated
physical USB/Thunderbolt acceptance on an Intel Mac has not yet been performed;
this is an explicitly accepted release exception based on prior device behavior
and the native Intel CI test run.

# MenuBarUSB-TB 0.1.2 – Deutsch

Diese Version ergänzt Universal-Mac-Unterstützung und härtet die ausschließlich
lokale Grenze der Geräteüberwachung.

## Kompatibilität

- Universal-App für Apple-Silicon- (`arm64`) und Intel-Macs (`x86_64`) mit
  macOS 13 oder neuer
- Version 0.1.1 bleibt ausschließlich für Apple Silicon

## Änderungen

- Zuverlässigere Bündelung von Aktualisierungen bei USB-, Thunderbolt- und
  USB4-Geräteereignissen
- Sicherere Verarbeitung von in der Menüleiste angezeigten Gerätemetadaten
- Entfernt nicht benötigte Berechtigungen für Nutzerdateien und ausgehende
  Netzwerkverbindungen; die App behält nur Sandbox- und USB-Geräteberechtigungen
- Die CI führt die Tests nun nativ auf Apple Silicon und Intel aus und der
  Release prüft beide ausführbaren Slices

## Validierungshinweis

Das Release-Artefakt wird für beide ausführbaren Slices gebaut und geprüft.
Eine eigene physische USB-/Thunderbolt-Abnahme auf einem Intel-Mac wurde noch
nicht durchgeführt; dies ist eine ausdrücklich akzeptierte Release-Ausnahme,
gestützt auf das bisherige Geräteverhalten und den nativen Intel-CI-Testlauf.
