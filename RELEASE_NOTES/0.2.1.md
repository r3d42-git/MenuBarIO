# PortGlance 0.2.1

This maintenance release makes PortGlance smaller, clearer and more native to
macOS without changing how connected hardware is discovered.

## Changes

- Simplifies the menu bar to the fixed USB and Bluetooth symbols with their
  decimal device counts; the optional wired-LAN indicator remains available
- Always shows useful device details and detected USB speed, lets the device
  list fit its rendered content, and keeps System Information directly
  accessible
- Replaces the former settings categories with one compact view and introduces
  a single `System / Light / Dark` appearance control
- Uses native macOS switches and host-window appearance so menu material, text
  and controls stay consistent in every appearance
- Replaces blue information buttons and expandable help text with concise,
  action-oriented setting labels
- Migrates existing appearance choices and removes retired preferences, code,
  resources, tests and localization entries

## Compatibility and privacy

- Universal app for Apple Silicon (`arm64`) and Intel (`x86_64`) Macs running
  macOS 13 or newer
- Device information remains local; the app contains no telemetry, analytics,
  update checks or network client code

## Validation note

The complete automated gate, static analysis, Universal build, local launch
smoke test and user visual inspection passed. This release does not change USB,
Thunderbolt, USB4, Bluetooth or Ethernet discovery behavior, so the documented
hardware validation remains applicable.

# PortGlance 0.2.1 – Deutsch

Dieses Wartungsrelease macht PortGlance kleiner, übersichtlicher und stärker
an macOS angelehnt, ohne die Erkennung angeschlossener Hardware zu verändern.

## Änderungen

- Vereinfacht die Menüleiste auf die festen USB- und Bluetooth-Symbole mit
  dezimalen Gerätezahlen; die optionale Anzeige für aktives Kabel-LAN bleibt
  verfügbar
- Zeigt nützliche Gerätedetails und die erkannte USB-Geschwindigkeit immer an,
  passt die Geräteliste an ihren gerenderten Inhalt an und hält die
  Systeminformationen direkt erreichbar
- Ersetzt die bisherigen Einstellungskategorien durch eine kompakte Ansicht
  und führt eine einzige Auswahl `System / Hell / Dunkel` ein
- Verwendet native macOS-Schalter und die Darstellung des Hostfensters, damit
  Menü-Material, Text und Bedienelemente in jeder Darstellung zusammenpassen
- Ersetzt blaue Info-Schaltflächen und aufklappbare Hilfetexte durch kurze,
  handlungsorientierte Einstellungsbezeichnungen
- Migriert bestehende Darstellungswahlen und entfernt überholte Einstellungen,
  Codepfade, Ressourcen, Tests und Übersetzungen

## Kompatibilität und Datenschutz

- Universal-App für Apple-Silicon- (`arm64`) und Intel-Macs (`x86_64`) mit
  macOS 13 oder neuer
- Geräteinformationen bleiben lokal; die App enthält weder Telemetrie,
  Analysen, Update-Abfragen noch Netzwerk-Client-Code

## Validierungshinweis

Die vollständige automatische Prüfkette, die statische Analyse, der
Universal-Build, der lokale Starttest und die Sichtprüfung des Benutzers waren
erfolgreich. Dieses Release verändert weder USB-, Thunderbolt-, USB4-,
Bluetooth- noch Ethernet-Erkennung; die dokumentierte Hardware-Abnahme bleibt
daher gültig.
