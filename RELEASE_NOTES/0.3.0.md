# PortGlance 0.3.0

This feature release makes the physical USB and Thunderbolt/USB4 topology more
directly visible while keeping PortGlance local-only and compact.

## Changes

- Adds a collapsible Thunderbolt/USB4 Ports group showing every physical host
  connector, its attached device or free state, active protocol and negotiated
  or maximum link speed
- Detects downstream Thunderbolt/USB4 connectors exposed by docks and groups
  them under their owning device
- Places built-in USB hubs below This Mac and tunneled hubs below their owning
  Thunderbolt/USB4 device instead of grouping hubs only by chip vendor
- Shows Thunderbolt/USB4 devices only at their physical ports while retaining
  them in the overall connected-device and menu-bar count
- Keeps USB devices connected through Thunderbolt-capable USB-C connectors in
  USB Devices rather than treating them as native Thunderbolt attachments
- Separates USB tier and port capability from the trailing negotiated link
  rate, including exact `1.5 Mbps` display for USB Low-Speed

## Compatibility and privacy

- Universal app for Apple Silicon (`arm64`) and Intel (`x86_64`) Macs running
  macOS 13 or newer
- Device information remains local; the app contains no telemetry, analytics,
  update checks or network client code

## Validation note

The complete automated gate, static analysis, Universal build, local launch
smoke test and user visual inspection passed. Physical validation on an M4 Pro
Mac mini covered all three rear host ports, TerraMaster TDAS and D1 SSD Pro,
the Anker Thunderbolt 4 Mini Dock, hub ownership and a live connection change.
GitHub CI validates the code natively on both Apple Silicon and Intel. Physical
validation of the new topology on Intel hardware will be completed later using
the published v0.3.0 GitHub artifact; this initial release does not claim that
physical Intel acceptance has already been performed.

# PortGlance 0.3.0 – Deutsch

Dieses Funktionsrelease macht die physische USB- und Thunderbolt-/USB4-Topologie
direkter sichtbar und hält PortGlance zugleich kompakt und rein lokal.

## Änderungen

- Fügt eine einklappbare Gruppe für Thunderbolt-/USB4-Ports hinzu, die jeden
  physischen Hostanschluss, das angeschlossene Gerät oder den freien Zustand,
  das aktive Protokoll und die ausgehandelte beziehungsweise maximale
  Verbindungsgeschwindigkeit zeigt
- Erkennt nachgelagerte Thunderbolt-/USB4-Anschlüsse von Docks und gruppiert
  sie unter ihrem zugehörigen Gerät
- Ordnet integrierte USB-Hubs Dieser Mac und getunnelte Hubs ihrem
  Thunderbolt-/USB4-Gerät zu, statt Hubs nur nach Chip-Hersteller zu gruppieren
- Zeigt Thunderbolt-/USB4-Geräte nur an ihren physischen Ports, zählt sie aber
  weiterhin im Gesamt- und Menüleistenzähler mit
- Belässt USB-Geräte an Thunderbolt-fähigen USB-C-Anschlüssen unter USB-Geräte,
  statt sie als native Thunderbolt-Verbindungen darzustellen
- Trennt USB-Klasse und Portfähigkeit von der rechts angezeigten ausgehandelten
  Geschwindigkeit, einschließlich der exakten Anzeige `1.5 Mbps` für USB
  Low-Speed

## Kompatibilität und Datenschutz

- Universal-App für Apple-Silicon- (`arm64`) und Intel-Macs (`x86_64`) mit
  macOS 13 oder neuer
- Geräteinformationen bleiben lokal; die App enthält weder Telemetrie,
  Analysen, Update-Abfragen noch Netzwerk-Client-Code

## Validierungshinweis

Die vollständige automatische Prüfkette, die statische Analyse, der
Universal-Build, der lokale Starttest und die Sichtprüfung des Benutzers waren
erfolgreich. Die physische Abnahme am M4-Pro-Mac-mini umfasste alle drei
rückseitigen Hostanschlüsse, TerraMaster TDAS und D1 SSD Pro, das Anker
Thunderbolt 4 Mini Dock, die Hub-Zuordnung und eine laufende Anschlussänderung.
Die GitHub-CI prüft den Code nativ auf Apple Silicon und Intel. Die physische
Abnahme der neuen Topologie auf Intel-Hardware wird später mit dem
veröffentlichten GitHub-Artefakt von v0.3.0 nachgeholt; dieser erste Release
beansprucht nicht, dass die physische Intel-Abnahme bereits erfolgt ist.
